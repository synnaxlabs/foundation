- **S11** The home's gate is the only control check. Unknown control state means "not
  in control". The home publishes control state on the channel the index points at,
  once per handoff. A writer asks for authority at open, capped by access. Authority 255
  cannot be taken. The control lease is an optional writer setting. There is no control
  policy.
  The control channel is of type `string` (#1201; `laptop.architect-2`:
  https://github.com/synnaxlabs/foundation/issues/3638#issuecomment-6299041639). Each
  sample is a JSON object, `{"subject", "via" (UUID of the node key), "authority",
  "after" (ns)}`, or `{}` when no writer holds control. `after` is the newest live
  stamp of the index at the handoff, absent when it has none. The subject of a
  command at stamp `t` is the holder of the last control sample whose `after` is
  below `t`. The stamp of a sample is mesh time at the home, strictly after the
  newest stamp of the control index. The person chose D, 2026-10-20T19:03Z, through
  `laptop.monitor`
  (https://github.com/synnaxlabs/foundation/issues/3634#issuecomment-6298877613,
  proposed at
  https://github.com/synnaxlabs/foundation/issues/3634#issuecomment-6297861322).
